3D U‑Net Segmentation of the HipMRI Dataset (COMP3710 Task 7)

This project implements a 3D U‑Net model to perform automatic segmentation of the hippocampus from volumetric magnetic resonance (MR) scans provided by the HipMRI Study. Unlike 2D approaches that operate on individual slices, a 3D U‑Net processes the entire volume and thus preserves the spatial context across all three dimensions. The goal of this assignment is to train a 3D segmentation model, evaluate it on an independent test set and report the results.

Dataset

The HipMRI dataset is organised into separate training and testing folders. Each sample consists of a 3D MR image and a corresponding binary mask where voxels inside the hippocampus region are labelled as 1 and all other voxels are 0. The directory structure is:
HipMRI_study_complete_release_v1/
├── semantic_MRs_anon_train/        (training MR volumes)
├── semantic_labels_anon_train/     (training masks)
├── semantic_MRs_anon_test/         (testing MR volumes)
└── semantic_labels_anon_test/      (testing masks)
For each volume in semantic_MRs_anon_train there is an identically‑named mask in semantic_labels_anon_train, and similarly for the test set. The training set was split 80/20 into a training and validation subset; the test set was held out completely for final evaluation.

Method
Architecture

The model adopts a 3D U‑Net architecture built from an encoder–decoder structure with skip connections. The encoder (contracting path) repeatedly applies convolutions followed by downsampling to extract hierarchical features from the volume. At the bottleneck, the spatial resolution is smallest and the feature representation most abstract. The decoder (expansive path) upsamples the feature maps back to the original resolution while concatenating them with the corresponding encoder features via skip connections. These skip connections restore fine‑grained spatial details that might otherwise be lost during downsampling

geeksforgeeks.org
. By fusing high‑level context and low‑level details, the U‑Net can precisely locate object boundaries
geeksforgeeks.org
. Our implementation uses 3 encoder/decoder stages with 3×3×3 convolutions, batch normalisation and ReLU activations, and transposed convolutions for upsampling.

Training procedure

Pre‑processing: Each 3D volume is downsampled by a factor of 2 to reduce memory requirements and accelerate training. During training, random 96×96×96 patches are extracted as input to encourage spatial diversity. For evaluation we feed the entire downsampled volume.

Loss function: We optimise a combination of binary cross‑entropy (BCEWithLogitsLoss) and Dice loss. The Dice loss directly measures overlap between prediction and ground truth and helps counteract class imbalance.

Optimisation: The model is trained for 20 epochs using the Adam optimiser with a learning rate of 1 × 10⁻⁴ and a batch size of 1. Mixed‑precision training (torch.amp) accelerates computation on the GPU while maintaining numerical stability.

Environment: Training was performed on a Windows machine with a NVIDIA GeForce RTX 5070 Ti GPU (CUDA 12.8) using PyTorch 2.9.0+cu128 and Python 3.11.

Implementation

The project code consists of the following components:File	Description
dataset.py	Custom HipMRIDataset class that loads NIfTI volumes and masks, optionally downsamples them and extracts random patches.
modules.py	Defines the UNet3D model with three encoder–decoder blocks and skip connections.
train_template.py	Training script that initialises the dataset, splits it into train/validation, trains the model with mixed precision and records the loss and Dice coefficient per epoch. It also plots and saves the training curves.
predict.py	Evaluation script that loads the trained model and computes Dice scores for each test volume.
unet_hipmri.pt	Saved model weights after training.
loss_curve.png & dice_curve.png	Visualisations of training loss and Dice coefficient over epochs (see Results section).
dice_scores.txt	Text file listing the Dice score for each test volume and the mean Dice.

Usage

To reproduce these results, follow the steps below. All commands assume the current directory contains the project files.

Install dependencies:
# create and activate a virtual environment (optional)
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
.venv\Scripts\activate    # Windows

# install required packages
pip install -r requirements.txt
Train the model:
python train_template.py
This script trains the 3D U‑Net for 20 epochs on the downsampled training set. After training, it saves the model weights to unet_hipmri.pt and generates loss_curve.png and dice_curve.png.
Evaluate on the test set:
python predict.py \
  --image_dir D:/RICH/data/HipMRI_study_complete_release_v1/semantic_MRs_anon_test \
  --mask_dir  D:/RICH/data/HipMRI_study_complete_release_v1/semantic_labels_anon_test \
  --model_path unet_hipmri.pt
Replace the image_dir and mask_dir paths with the location of your test data if different. The script prints the Dice score for each test volume and computes the mean Dice. It also writes these scores to dice_scores.txt.
